# MATLAB-Signal-Processing

Simple Signal Processing Tool Using MATLAB
Task 5 — Signal Processing

A simple MATLAB GUI application that demonstrates basic signal-processing techniques including signal generation, noise filtering, Fourier Transform analysis, and dominant-frequency detection.

Problem Description

Signals can contain useful information as well as unwanted noise. Signal processing techniques can be used to reduce noise and identify important frequency components.

Technology Used
MATLAB
MATLAB Signal Processing Toolbox
Features: Generate a clean sinusoidal signal , Add high-frequency and random noise , Display the noisy signal , Apply a low-pass filter , Perform Fast Fourier Transform (FFT) , Display the frequency spectrum , Identify the dominant frequency , Simple graphical user interface.
