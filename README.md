# MATLAB-Signal-Processing

Simple Signal Processing Tool Using MATLAB
Task 5 — Signal Processing

I took a real ECG signal from the MIT-BIH Arrhythmia Database and loaded it into MATLAB using the WFDB Toolbox. First, I analyzed the raw signal and identified the need for preprocessing because ECG recordings can contain baseline wander, power-line interference and high-frequency noise. I then applied suitable digital filtering to reduce these unwanted components while preserving the important ECG waveform. After filtering, I performed FFT to study the frequency components. I then detected the R-peaks, calculated the RR intervals and estimated the heart rate. Finally, I evaluated the processing results using suitable signal-quality measures and compared the raw and processed signals.”
